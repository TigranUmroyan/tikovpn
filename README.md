# SA-MP Mobile Web — прототип 1.0

Это собственная браузерная мини-игра с простым изометрическим городом, сенсорным управлением, машинами (режим ускорения/посадки как прототип), стрельбой-визуализацией, чатом и синхронизацией игроков через WebSocket.

## Важно
Это НЕ клиент GTA San Andreas, НЕ SA-MP/open.mp и НЕ совместимо с Arizona RP или произвольными SA-MP-серверами. Нельзя подключить этот проект к `62.148.135.15:7777`: протокол и игровой мир другие.

## Запуск локально на компьютере
Нужен Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:8080`? Сервер в этой минимальной сборке предоставляет WebSocket, а не HTTP-страницу. Для локальной проверки откройте `index.html` в браузере и в поле адреса укажите `ws://localhost:8080`. Чтобы страница и WebSocket работали на одном адресе, разместите `index.html` на статическом HTTPS-хостинге, а `server.js` — на Node-хостинге.

## Игра с iPhone и друзьями
1. Разместите `index.html` на HTTPS-хостинге.
2. Запустите `server.js` на Node.js-хостинге с доступным WebSocket-портом.
3. Настройте TLS/WSS на хостинге (для HTTPS-страницы Safari обычно требует `wss://`, а не `ws://`).
4. Откройте страницу в Safari и укажите адрес `wss://ваш-домен`.
5. Друзья открывают ту же страницу и подключаются к тому же WebSocket-серверу.

`ws://localhost:8080` работает только если сервер запущен на том же устройстве, где открыт браузер. Для iPhone это обычно не так.

## Состав
- `index.html` — клиент игры.
- `server.js` — WebSocket-сервер.
- `package.json` — зависимости и команда запуска.

Это стартовый прототип: нет коллизий/физики уровня GTA, авторизации, античита, сохранения прогресса, голосового чата, полноценной системы оружия или реального подключения к сторонним игровым серверам.
